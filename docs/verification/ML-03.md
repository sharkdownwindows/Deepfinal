# ML-03 Verification — Batch Generation

## Implemented

- Reads the resolved run config and versioned prompt/seed banks.
- Generates the fixed prompt × seed matrix for the base model and, when given
  an adapter, the adapter variant.
- Creates one seeded generator per sample and records mode, prompt, seed,
  model revision, adapter scale, settings, and image path in JSONL metadata.
- Checks for missing, duplicate, unexpected, or absent image outputs before
  publishing the metadata file; existing outputs are not overwritten.
- Base and adapter samples receive distinct IDs in downstream metrics.

## Verification evidence

`tests/test_generation.py` runs a fake pipeline over all 8 prompts × 4 seeds ×
2 modes and checks 64 unique generators and existing output files. This checks
the batch contract without loading model weights. It does not establish runtime
compatibility with a real Diffusers checkpoint or GPU.
