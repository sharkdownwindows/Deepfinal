# QA-01 Verification — Vertical Slice

## Implemented path

`scripts/run_vertical_slice.py` runs the configured DreamBooth-LoRA pilot,
reloads the saved adapter, writes the generated pilot image and evaluation
metadata, then scores that sample with DINOv2 and CLIP. The run artifact keeps
resolved config, environment, dataset-subset hashes, logs, adapter, status,
generation metadata, and timing/GPU-memory metrics.

Run on a CUDA runtime after installing the documented project and Diffusers
dependencies and copying the private dataset into the configured paths:

```bash
python scripts/run_vertical_slice.py \
  --config configs/pilot/dog_plush_n10_r16_ts42.yaml \
  --diffusers-script third_party/diffusers/examples/dreambooth/train_dreambooth_lora.py
```

The configured pilot uses one training step and four inference steps. It checks
the interfaces and artifact contract; it is not a research-quality model or
ML-04/ML-05 result.

- The full train/load/generate/score command has not been run. This machine has
