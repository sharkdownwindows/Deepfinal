# ML-04 Verification — Data-Size Sweep

## Sweep definition

`configs/ml04_sweep.yaml` is the source for the 3 concepts × 4 data sizes
(`n={1,3,5,10}`) matrix. It fixes rank/alpha at 16, training seed at 42,
resolution at 512, learning rate at `1e-4`, and training budget at 500 steps.
The nested subsets are selected from each versioned manifest and their hashes
are checked before training; only the selected images are copied into that
run's ignored artifact directory.

`scripts/run_sweep.py --dry-run` preflights all 12 configs without model
downloads or training. The execution mode records each result in a timestamped
CSV; failed runs retain their run error and receive a separate
`owner_review_required` rerun decision. The script never overwrites an existing
run or automatically reruns a failure.

```bash
python scripts/run_sweep.py --dry-run
python scripts/run_sweep.py \
  --diffusers-script third_party/diffusers/examples/dreambooth/train_dreambooth_lora.py
```

## Verification status

`tests/test_run_sweep.py` checks that the matrix expands to 12 controlled
cells. The dry-run preflight validates local manifests and image counts. The
actual 12-run GPU sweep has not been executed: the available local GPU is a
